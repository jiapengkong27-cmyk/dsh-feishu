# dsh-feishu-observer

DSH ↔ 飞书 连接看板与启动通知。

- 右下角常驻状态胶囊，点击展开检查详情、自检修复步骤和事件时间线。
- 用不上时点“断开连接”（两次点击确认）立刻停掉订阅与发送；点“恢复连接”重新接上。
- 断线时自动探测网络、重启桥接订阅并复查连接。
- 每次 DSH 启动向飞书发送上线通知。

配了 `dsh-feishu-board`（左侧栏整页看板）之后，可以把浮窗关掉：`showCapsule: false`，本插件退化成纯引擎，界面交给侧栏。

安装后刷新一次 DSH 页面即可看到。完整说明见 [docs/DETAIL.md](docs/DETAIL.md)。

# 飞书连接面板（左侧栏）

**一句话：** 左侧栏多一个飞书图标，点开是整页的连接看板——看得清、顺手能断开。

## 入口在哪

### 状态指示灯（不打开页面也看得到）

| 位置 | 什么时候可见 | 长什么样 |
| --- | --- | --- |
| 会话标题栏右侧「● 飞书」胶囊 | 打开任意会话时（`conversation.session.header.utilities`，order 5） | 圆点 + 文案；点一下直接跳到看板 |
| 左侧栏飞书图标右下角小圆点 | 一直可见，包括新会话首页和左栏收起成竖条时 | 6px 圆点 |

颜色语言（不单靠颜色区分，也看形状）：

| 状态 | 圆点 |
| --- | --- |
| 已连接 | 实心绿 |
| 部分异常 | 实心黄 |
| 连接中断 | 实心红 + 1.5s 呼吸动画 |
| 已手动断开 / 未知 | 空心灰环（无填充） |

两个指示灯共用一个 20 秒轮询（模块内单例），不随页面切换重复请求；看板页面自己另有 6 秒的更快轮询，因为它同时要驱动操作。读失败时保留上一次的颜色，不会闪成灰。

### 图标入口

左侧栏（全局面板图标那一条）新增一个飞书图标，排在「定时任务」与「Context」之间。

- 图标右下角有状态点：🟢 已连接、🟡 部分异常、🔴 连接中断、⚪ 已手动断开 / 读不到状态。
- 悬停显示「飞书连接：<状态>」。
- 点击切到整页看板；再点其他图标切回会话，看板卸载后不再轮询。

> 插件的样式表在插件挂载时注入 `document.head`，而不是跟着页面组件走——否则离开看板页时，标题栏胶囊和侧栏圆点会拿到零宽度的裸 `span`，等于看不见。

## 页面里有什么

| 区域 | 内容 |
| --- | --- |
| 顶部 | 状态徽标、上次检测时间、复查间隔、通知目标（断开 / 恢复动作统一放在「常用操作」里，不在顶部重复） |
| 连接检查 | lark-cli、飞书授权、事件长连接、桥接发送器、开放平台接口、消息入站、上线通知，逐项状态与修复建议 |
| 常用操作 | 立即检测、一键排查修复、发送测试消息、断开飞书连接 |
| 最近一次操作 | 断开 / 恢复 / 自动排查的逐步结果 |
| 事件记录 | 上线、断线、恢复、修复、手动断开的完整时间线（可展开到 60 条） |

断开态下页面只保留「恢复飞书连接」，其余动作隐藏——避免点了一个注定失败按钮。

## 断联到底做了什么

页面本身不碰进程和计划任务，它调用 `dsh-feishu-observer` 的 `disconnect` / `connect` 动作，由那边执行：

1. 停用 Windows 计划任务 `FeishuCLIBridgeSender`；
2. 结束 `lark-cli event consume` 订阅进程；
3. 停止事件总线守护进程；
4. 暂停 DSH 里只为飞书服务的定时任务（`pauseSchedules`）；
5. 复查确认断干净。

恢复时反向执行并刷新发送器心跳。断开状态持久化在 `%DSH_HOME%/feishu-observer/state.json`，重启 DSH 后仍然断开。

## 依赖与边界

- **依赖 `dsh-feishu-observer`**：本插件只有 UI，状态和动作全部来自它的本地同源接口 `/feishu-observer/status|action`。没装或没启用时，页面会显示「找不到连接看板服务」并提示怎么装。
- 页面每 6 秒读一次状态，侧栏图标每 30 秒读一次；都只打本机回环地址，不联网。
- 所有文字跟随 DSH 语言（中文 / English）。

## 开发

```bash
node scripts/smoke-client.mjs   # 桩 React 渲染四种状态，断言按钮集
```

修改 `client.js` 后刷新 DSH 页面即可生效（无需重启宿主）。

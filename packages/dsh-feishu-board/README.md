# dsh-feishu-board

左侧栏飞书入口：点开就是一整页的连接看板，顺手断开 / 恢复飞书链路。

- **离开这个页面也能看到状态**：会话标题栏右侧常驻「● 飞书」胶囊，绿=已连接、黄=部分异常、红=中断（会呼吸闪烁）、空心灰=已手动断开 / 未知；点它直接跳到看板。
- 左侧栏图标右下角也有同色小圆点，没有打开会话时也能瞄一眼。
- 整页展示 7 项连接检查、最近一次操作、事件时间线。
- 顶部一键「断开飞书连接」（两次点击确认）和「恢复飞书连接」。

状态与动作都走 [dsh-feishu-observer](../dsh-feishu-observer) 的 `/feishu-observer/*` 接口，所以桥接只有一个人管；那个插件的浮窗胶囊已经用 `showCapsule: false` 关掉，界面只保留这个页面。完整说明见 [docs/DETAIL.md](docs/DETAIL.md)。
